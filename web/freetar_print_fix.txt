FREETAR PRINT FIX

Open a freetar.de chord page, click this bookmark, then print or Save as PDF.
Everything from v5 (no nav bar, no "View on" column, Capo under Tuning, no buttons, no blue bars,
black-on-white chord diagrams, song text printed as one plain column)

How the fix works / what to watch: for each diagram the script checks the dot positions against a
built-in list of standard shapes for that chord (Em, Am, D, E, G, E7, Dsus4, Cadd9, G/F#, Em7, D6/9,
Em9, Dmaj9, E5, D5, A7sus4). If the dots match, open strings get "o". A chord that is not on the list,
or whose dots don't match, is left exactly as the site draws it (open strings still shown as "x").

PRINT TIP: Portrait, Letter, 100% scale. Turn on "Background graphics" so the black finger dots print.

SETUP: create a bookmark and paste the javascript into the URL field
